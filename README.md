# Balatro 原版向模组

本项目的开发方向，是在完全基于《Balatro》原版内容与整体平衡性的前提下进行额外开发，对部分卡牌能力与高难度规则进行调整。

模组目前仍在持续测试与更新，现有数值并非最终版本。

---

## Balatro Balance Patch

**当前版本：** `v0.3.17`

针对原版内容制作的平衡调整包，不添加新卡牌或新机制。

本模组调整了多张偏弱或体验不佳的小丑牌，并重新设计蓝注、橙注与金注的部分规则，让更多构筑能够在高难度下发挥作用。

| 优惠券 | 调整内容 |
| --- | --- |

## Bulky Stakes

**当前版本：** `v0.1.17`

独立高难度扩展，在金注之后增加澳金注与小丑注。

### 澳金注

商店中的兼容小丑有 30% 概率获得“肥大”标签：

- 占据两个小丑栏位；
- 购买价格翻倍；
- 出售价格保持原价；
- 支持的筹码与倍率效果额外触发一次；
- 乘倍效果采用线性翻倍，例如 `X3` 变为 `X6`，而不是 `X9`；
- 回合结束金钱收益翻倍，包括延迟满足；
- 肥大与租赁共存时，每回合共扣除 `$6`；
- 肥大与易腐共存时，每回合减少 `2` 点易腐计数；
- 肥大不能与负片同时存在；
- 部分复用类、特殊功能类与传奇小丑不会获得肥大；
- 乌合之众、审判、怨灵与灵魂生成的小丑牌不会获得任何标签；
- 安卡和隐形小丑生成的副本会保留被复制小丑的标签，栏位不足时按照“被挤压”规则处理。

### 小丑注

小丑注继承澳金注的全部规则，并进一步提高各底注所需的基础分数。

| 底注 | 基础分数 |
| ---: | ---: |
| 1 | 300 |
| 2 | 1,100 |
| 3 | 3,900 |
| 4 | 12,000 |
| 5 | 37,000 |
| 6 | 100,000 |
| 7 | 200,000 |
| 8 | 400,000 |

底注 9 及之后以 400,000 为锚点，继续使用原版无尽模式的指数增长公式。

## Cartomancer Deck

**当前版本：** `v0.1.9`

以强化塔罗牌为核心的独立牌组模组。使用占卜师牌组时，多张原版塔罗牌会获得加强，但正常游戏过程中不再获得星球牌、天体包、黑洞、恍惚与蓝色蜡封。

所有塔罗牌和特殊规则调整都只在占卜师牌组中生效，不会影响其他牌组。

### 牌组规则

- 商店卡牌基础权重调整为：小丑牌 `20`、塔罗牌 `4`、星球牌 `0`。
- 标准卡牌包的出现权重提高至原版的 `1.5` 倍。
- 幻灵包的出现权重提高至原版的 `2` 倍。
- 塔罗包与小丑包的出现权重保持不变。
- 正常生成路径不会出现星球牌、天体包、黑洞或恍惚。
- 随机生成幻灵牌的小丑牌也不会生成恍惚。
- 标准卡牌包及其他随机蜡封来源不会产生蓝色蜡封。
- 证书生成的卡牌只会获得红色、金色或紫色蜡封，三者概率均为 `1/3`。
- 通过作弊工具直接生成的星球牌、黑洞、恍惚或蓝色蜡封仍然可以正常使用。

## 安装要求

- Steam 版《Balatro》
- Lovely
- Steamodded `1.0.0~`

三个模组均可单独安装，也可以同时使用。将对应模组文件夹放入：

`%AppData%\Balatro\Mods\`
