目前MOD的开发方向为完全基于原版游戏（以及平衡性）进行额外的开发，对部分卡牌能力进行调整
Balatro Balance Patch｜v0.3.11
针对原版内容制作的平衡调整包，不添加新卡牌或新机制。调整了多张偏弱或体验不佳的小丑牌，并重新设计蓝注、橙注与金注的部分规则，让更多构筑能够在高难度下发挥作用。
针对原版小丑调整如下：
贪婪小丑、色欲小丑、愤怒小丑、暴食小丑：对应花色计分时，由 +3 倍率提高至 +4 倍率。
旗帜：每次剩余弃牌由 +30 提高至 +40 筹码。
神秘之峰：零弃牌时的 +15 倍率改为 +150 筹码。
八号球：每张计分的8有 1/4 概率生成一张《愚者》。
恐怖面孔：每张计分人头牌由 +30 提高至 +40 筹码。
学者：改为罕见品质；计分A由 +20 筹码、+4 倍率提高至 +40 筹码、+5 倍率。
徒步者：售价改为 $7；每张计分牌由永久 +5 筹码改为永久 +1 倍率。
积分卡：由罕见品质改为普通品质。
叠加态：改为稀有品质、售价 $10；带A的顺子会生成上一次使用的塔罗牌或星球牌的负片版本。
红牌：每跳过一个补充包，由 +3 提高至 +4 倍率。
方形小丑：初始自带 +16 筹码，保留原本每次增长 +4 筹码的效果。
石头小丑：完整牌组中每张石头牌提供的筹码由 +25 提高至 +50。
回溯：本赛局每跳过一个盲注的成长由 X0.25 提高至 X0.5。
花盆：罕见品质、售价 $6；得分牌包含2/3/4种花色时，分别提供 X1.25 / X2 / X3 倍率。
上路吧杰克：每弃掉一张J的成长由 X0.5 提高至 X0.75。
一家人：四条牌型提供的倍率由 X4 提高至 X5。
部落：同花牌型提供的倍率由 X2 提高至 X2.5。
卫星：本赛局每使用过一种不同的星球牌，回合结束收益由 $1 提高至 $2。
提靴带：每持有 $5，由 +2 提高至 +4 倍率。
黄金门票：每张打出并计分的黄金牌获得 $5。
冲向月球：金注下每持有 $10，额外获得 $2 利息。
注难度调整如下：
蓝注：不再减少一次弃牌，改为启用易腐小丑。
紫注：保留原版的盲注分数增长。
橙注：启用租赁小丑。
金注：每持有 $10 获得 $2 利息，基础利息上限为 $4。
《种子基金》和《摇钱树》会将金注利息门槛与上限分别提高至 $40/$8 和 $80/$16。

Bulky Stakes｜v0.1.12
独立高难度扩展，在金注之后增加澳金注与小丑注。澳金注会让商店中的兼容小丑有30%概率获得“肥大”：占据两个栏位、购买价格翻倍，同时效果翻倍。小丑注则进一步提高各底注所需分数，底注8基础分数达到40万。
两个模组可以单独安装，也可以同时使用。均需安装 Lovely 与 Steamodded 1.0.0~
